# Backend Laravel

Ce dossier contient l’API Laravel du projet KANBAN.

## Commandes utiles

- `composer install` : installe les dépendances PHP.
- `php artisan migrate` : applique les migrations MySQL.
- `php artisan serve` : lance le serveur de développement.

Les détails d’architecture, de flux métier et de déploiement sont centralisés dans le [README racine](../README.md) et sur la page `/docs` du frontend lorsque `VITE_DOCS_ENABLED=true`.***
